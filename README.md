# Stock-Prediction-Model

An LSTM model that combines Yahoo Finance price data with Reddit/Twitter
sentiment to predict a meme-stock ticker (default: GME).

## Files

- `Meme_Stock_Prediction_Model.py` — the main script: data collection
  (yfinance, PRAW, snscrape), TextBlob sentiment, RSI/MACD features, an LSTM
  trained for 50 epochs, and a results plot.
- `enhanced meme stock prediction model.py` — a **continuation fragment**,
  not a standalone script: cross-validation, a backtester and a Flask
  deployment section that build on names and saved artifacts from the main
  file. See the header comment in the file.

- `make_sample_data.py` — regenerates the synthetic sample social data
  in `sample_data/` (see Demo mode).
- `sample_data/` — `reddit_posts.csv` / `twitter_posts.csv` (SYNTHETIC
  sample posts, generated by `make_sample_data.py`) and
  `gme_prices.csv` (real GME daily prices, 2021-2023, downloaded from
  Yahoo Finance and cached on first demo run).

## How to run

### Demo mode (no credentials needed)

```bash
pip install -r requirements.txt
python Meme_Stock_Prediction_Model.py --demo
```

Runs the full pipeline — TextBlob sentiment over the bundled sample
posts → RSI/MACD + combined-sentiment features on real GME prices →
LSTM training (50 epochs) → test-set evaluation — and saves
`prediction_plot.png`. The social-media data is **synthetic**, so the
results demonstrate the pipeline only; they are not a real backtest.

Verified output (Nov 2026):

```

```

### Live mode

```bash
REDDIT_CLIENT_ID=... REDDIT_CLIENT_SECRET=... REDDIT_USER_AGENT=... \
python Meme_Stock_Prediction_Model.py
```

Requirements in practice: live internet access (Yahoo Finance) and
**your own Reddit API credentials** in the environment variables above
(the values in the file are placeholders; without them the script
prints instructions and exits). Twitter/X scraping via snscrape has
been broken by upstream changes for a long time — if tweet collection
fails, the live path prints a warning and continues Reddit-only.

## Repairs that made it run (Nov 2026)

- Optional imports: `praw`, `snscrape` and `pandas_ta` are imported
  tolerantly; `create_features` falls back to built-in Wilder-RSI /
  MACD implementations when pandas_ta is absent (pandas_ta's `macd()`
  returns three columns, so the original two-column assignment would
  have failed even with it installed).
- Two silent date bugs in `process_social_data`: Reddit's epoch-second
  timestamps were parsed as nanoseconds (everything landed in 1970),
  and `.dt.date` objects never matched the price frame's DatetimeIndex
  in the merge — sentiment previously flowed through as all zeros.
- The sentiment merges in `create_features` now run on a plain `date`
  column (index-merging corrupted the frame under current pandas).
- Feature rows are `dropna()`-ed before scaling; the original scaled
  the RSI/MACD warm-up NaNs straight into training.
- Reddit credentials are read from the environment instead of the
  hard-coded placeholders.
